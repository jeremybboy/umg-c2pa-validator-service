Inside the library

Content binding

Recompute the protected-content hash.
Compare it with the manifest’s binding.

Claim signature

Verify the signature on the claim.
Use the signer’s public key.

Signer trust

Check the certificate chain.
Apply the selected trust policy.

Reusable outside this Mac window. Another intake service can consume the same inspection report.

const report = await inspectFile(file);
Under the hood

Library used here: @contentauth/c2pa-node 0.12.0 from the Content Authenticity Initiative, backed by the native Rust implementation c2pa-rs.

Our src/validator/service.mjs calls Reader.fromAsset({ path: file, mimeType }, context). The SDK validates; our report mapper formats its evidence for the interface.

Other language options: the CAI SDK family also offers Python and C/C++ libraries backed by its Rust core. This app uses the Node.js library; those other bindings are alternative integration choices.

Test Mode: adds the bundled public test root to the selected trust policy. Content-binding and signature verification remain enabled.

SDK reference: opensource.contentauthenticity.org/docs/introduction/
