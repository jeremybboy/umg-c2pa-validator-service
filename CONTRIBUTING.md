# Contributing

Use a focused branch and pull request; the maintainer performs the final merge. Explain user-visible behavior, verification and remaining limitations. Preserve existing work and stage only intended paths.

Provide minimal reproducible examples made from audio you may share. Never attach credentials, private keys, internal delivery packages or company files to a public issue. Real validation regressions should use generated or explicitly licensed fixtures.

Every displayed validation success must be supported by the SDK result under a named policy. Synthetic AI results must stay visibly labelled. Unknown must never silently become pass, and no credentials must not be equated with AI-generated content.

See README for the current run/test commands and `AGENTS.md` for repository-specific implementation rules.
